# Sprint 1 Retrospective (Họp cải tiến)

## 1. Mặt làm tốt (What went well?)
* Cả nhóm phối hợp tốt, tuân thủ đúng tiến độ.
* Chia nhỏ công việc hợp lý.

## 2. Mặt chưa tốt (What didn't go well?)
* Ước lượng thời gian cho chức năng Đăng ký tài khoản còn hơi thiếu.
* Chưa đồng bộ chuẩn code ngay từ đầu.

## 3. Hành động cải thiện cho Sprint 2 (Action Items)
* Thống nhất Coding Convention trước khi viết code cho Sprint 2.
* Tăng cường trao đổi trên nhóm chat khi gặp Blocker.
