# Dự án VH-EStore - Hệ thống bán hàng trực tuyến

## Công nghệ sử dụng
* **Frontend:** ASP.NET MVC Razor Views / HTML / CSS / JavaScript
* **Backend:** ASP.NET / C# Web Application
* **Database:** SQL Server - MyeStoreDB
* **Architecture:** Web MVC + SQL Server

## Hướng dẫn cài đặt và chạy ứng dụng
1. Clone repository này về máy local.
2. Mở file solution trong Visual Studio.
3. Cấu hình chuỗi kết nối Database `MyeStoreDB` trong file `appsettings.json` hoặc `web.config`.
4. Chạy lệnh Update-Database (nếu dùng Entity Framework Migration).
5. Nhấn `F5` hoặc chọn `Run IIS Express` để khởi chạy ứng dụng.
